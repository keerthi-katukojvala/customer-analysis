# E-Commerce Customer Analytics

A data science project analyzing 541,000 transactions from an online retail dataset across 37 countries.

## Key Findings

- **Total Revenue**: $9.5M
- **Unique Customers**: 4,372 across 37 countries  
- **Key Insight**: Top 10% of customers generate 80% of revenue (Pareto principle)
- **Average Order Value**: $9.05

## Analysis Performed

1. **Data Cleaning**: Removed 24,915 transactions with missing/invalid data
2. **Exploratory Data Analysis**: Customer segmentation and spending patterns
3. **Trend Analysis**: Monthly revenue trends and seasonal patterns
4. **Visualizations**: 4-chart analysis dashboard showing purchase distribution, geographic patterns, and customer lifetime value

## Technologies

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- Data visualization and statistical analysis

## Files

- `customer_analysis.ipynb` - Complete analysis pipeline
- `customer_analytics.png` - Visualization outputs
- `Online_Retail.csv` - Source data (541K transactions)

## How to Use

Open `customer_analysis.ipynb` in Jupyter Notebook to see the full analysis workflow.
